# Яхт-чартер «Вітрило» — лабораторна робота 7 (Blazor, .NET 10, Interactive Server)

## Запуск
1. Потрібен .NET SDK 10 (`dotnet --list-sdks`).
2. З папки, де лежить `YachtCharter.csproj`:
   ```
   dotnet run --urls http://localhost:5127
   ```
   або відкрити `YachtCharter.csproj` у Visual Studio 2026 і натиснути F5.
3. Відкрити http://localhost:5127

## Формула вартості
- Ціна однієї яхти = (ціна за добу + доплата за екіпаж) × оплачувані доби
- Екіпаж: без шкіпера — 0 ₴, зі шкіпером — +1 500 ₴/доба, шкіпер і кок — +2 500 ₴/доба
- Тривалість: 1 доба, 3 доби, тиждень (7 діб, оплачується 6)
- Сума = ціна однієї яхти × кількість яхт (1–10)

## Контрольні розрахунки
| Вибір | Розрахунок | Очікувано |
|---|---|---|
| Бриз, 1 доба, без шкіпера, 3 яхти | 4 500 × 1 = 4 500; × 3 | 13 500,00 ₴ |
| Альбатрос, 3 доби, зі шкіпером, 2 яхти | (6 500 + 1 500) × 3 = 24 000; × 2 | 48 000,00 ₴ |
| Дельфін, тиждень, шкіпер і кок, 1 яхта | (9 000 + 2 500) × 6 = 69 000; × 1 | 69 000,00 ₴ |
