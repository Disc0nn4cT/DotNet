# Яхт-чартер «Вітрило» — лабораторні 7–8 (Blazor, .NET 10, Interactive Server, EF Core SQLite)

## Запуск
1. Потрібен .NET SDK 10.
2. З папки з `YachtCharter.csproj`: `dotnet run --urls http://localhost:5127` (або F5 у Visual Studio 2026).
3. Відкрити http://localhost:5127. API каталогу: http://localhost:5127/api/yachts

Під час першого запуску поруч із `.csproj` створюється `charter.db` із шістьма яхтами (файл не комітиться).
Кошик зберігається в пам’яті інтерактивної сесії: зберігається під час переходів між сторінками,
зникає після повного перезавантаження.

## Формула вартості
Ціна однієї яхти = (ціна за добу + доплата за екіпаж) × оплачувані доби (тиждень = 6 оплачуваних діб);
сума позиції = ціна однієї яхти × кількість яхт (1–10). Екіпаж: 0 / +1 500 / +2 500 ₴ за добу.

## Контрольні сценарії
| Дія | Очікувано |
|---|---|
| Бриз, 1 доба, без шкіпера, 1 яхта | 4 500,00 ₴ |
| Альбатрос, 3 доби, зі шкіпером, 2 яхти | 24 000,00 ₴ за одну; 48 000,00 ₴ за позицію |
| Дельфін, тиждень, шкіпер і кок, 1 яхта | 69 000,00 ₴ |
| Кошик: Альбатрос (48 000) + Бриз (4 500) | 2 рядки, 3 яхти, 52 500,00 ₴ |
| Видалити Альбатроса | залишається Бриз, 4 500,00 ₴ |
| Перейти на «Про чартер» і назад | кошик зберігся |
| F5 (повне перезавантаження) | кошик порожній, каталог на місці |
